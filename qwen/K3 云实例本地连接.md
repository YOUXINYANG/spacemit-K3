# macOS 连接 K3 云实例与文件传输

## 连接原理

```text
Mac 上的 SSH/scp → 本机 127.0.0.1:2222 → stunnel TLS 隧道 → K3 云实例
```

`bianbu@k3` 中的 `k3` 是实例主机名。实际外部连接地址来自控制台；通过隧道后，SSH 和 scp 使用本机地址 `127.0.0.1`。

准备两个 Mac 终端窗口：窗口 A 保持隧道运行，窗口 B 登录或上传文件。Mac 可按 `Command + 空格` 搜索“终端”，按 `Command + N` 新开窗口。

## 在 Mac 安装 stunnel

在 Mac 终端执行：

```bash
brew --version
brew install stunnel
```

如果找不到 `brew`，先按 [Homebrew 官网](https://brew.sh/)安装，并完成安装器最后的 `Next steps`，再安装 stunnel。参考 [stunnel 的 Homebrew 页面](https://formulae.brew.sh/formula/stunnel)。

## 创建配置并启动隧道

在 **Mac 窗口 A** 执行：

```bash
cat > "$HOME/stunnel-k3.conf" <<'EOF'
foreground = yes

[spacemit-ssh]
client = yes
accept = 127.0.0.1:2222
connect = 8aaa8763a0e5d85701a11f4c9b250108.gdriscv.com:2222
EOF

"$(brew --prefix stunnel)/bin/stunnel" "$HOME/stunnel-k3.conf"
```

`connect` 使用本次控制台给出的地址；换实例或控制台更新地址后，需要相应修改。

`foreground = yes` 让程序在当前窗口运行并显示日志。**保持窗口 A 打开**，没有返回命令提示符是正常现象。参考 [stunnel 官方说明](https://www.stunnel.org/howto.html)。

## 登录 K3

在 **Mac 窗口 B** 执行：

```bash
ssh -p 2222 bianbu@127.0.0.1
```

使用控制台提供的 Bianbu 登录密码，修改过密码则使用新密码。输入密码时不显示字符。首次连接如提示确认主机指纹，应核对平台信息后接受。

登录成功后可看到：

```text
bianbu@k3:~$
```

此时输入的命令在 K3 上执行。输入 `exit` 可返回 Mac：

```bash
exit
```

## 从 Mac 上传测试目录

确认隧道仍运行，在 **Mac 窗口 B** 执行：

```bash
ls "/Users/yxy/spacemit-K3/qwen/benchmarks/tcm-copy"

scp -P 2222 -r \
  "/Users/yxy/spacemit-K3/qwen/benchmarks/tcm-copy" \
  bianbu@127.0.0.1:~/qwen/
```

说明：`ssh` 指定端口用小写 `-p`，`scp` 用大写 `-P`；`-r` 表示上传整个目录。

上传后，重新登录，在 **K3 终端**检查：

```bash
ls -lh ~/qwen/tcm-copy/
```

本次初版的五个文件全部上传成功：`CMakeLists.txt`、`README.md`、`main.cpp`、`check_copy.h`、`test_check_copy.cpp`。后续更新增加了轮转及预取文件，可再次上传整个目录；同名文件会被覆盖，本地文件仍保留。

## 从 K3 下载实验日志

以下命令在 **Mac 本地终端**执行：

```bash
mkdir -p /Users/yxy/spacemit-K3/qwen/downloads

scp -P 2222 \
  bianbu@127.0.0.1:~/qwen/logs/tcm-copy-v3-stream.csv \
  /Users/yxy/spacemit-K3/qwen/downloads/
```

## 验证结果与常见问题

本阶段已确认：**本地文件上传成功，K3 能编译并运行上传的测试程序**。具体实验结果见 [memcpy1d 实验](memcpy1d%20实验.md)。

| 现象                                | 检查方法                                                                      |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| 找不到 `brew`                     | 安装 Homebrew，并完成 `Next steps`                                          |
| 隧道提示 `Address already in use` | 检查是否已启动同一隧道；也可修改 `accept` 的本地端口，同时修改 SSH/scp 端口 |
| SSH 提示 `Connection refused`     | 检查窗口 A 的 stunnel 是否仍运行、本地端口是否一致                            |
| 登录认证失败                        | 确认用户是 `bianbu`，使用当前实例的登录密码                                 |
| 找不到本地源码目录                  | 确认 scp 在 Mac 运行，且本地路径存在                                          |

使用完毕后，先退出 SSH，再到窗口 A 按 `Control + C` 结束隧道。下次连接时重新启动隧道即可，无需重复安装或创建配置。
